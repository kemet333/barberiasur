# Barbería Sur · barberiasur.es

Web de Barbería Sur (C/ Portugal, 3 · Albacete).

- Edita `src/page.html` (datos de la barbería en el bloque `CONFIG`, productos en `PRODUCTS`, reseñas en `REVIEWS`).
- Fotos: `fotos/isma.jpg`, `fotos/galeria-1.jpg` … `galeria-5.jpg`; productos en `productos/`.
- Ejecuta `python3 build.py` y sube los cambios: GitHub Pages publica la carpeta `docs/` en https://barberiasur.es.
